## 🏆 LP構成とストーリー設計（売れるLP仕様）

訪問者の心理変容に寄り添い、自然に来店意欲が高まる順番でセクションを構成しています：

1. **ファーストビュー（FV）**:
   - サブコピー：「あなたはもう、美容院に迷いません！」と言い切り宣言。
   - キャッチコピー：「独自の技術で──。乾かすだけで、美しくまとまる髪へ。」をゴールドグラデーションで強調。
   - スタイリッシュで立ち止まりたくなる洗練デザイン。思わずタップしたくなるパルス鼓動＆光沢シャインアニメーション付き予約ボタン。
2. **問題提起（Problem）**:
   - 年齢によるパサつき・うねり、毎朝のアイロン時間、大型サロンの視線など、大人女性のリアルな悩みを浮き彫りに。
   - 「実はその原因、【骨格に合っていないカット】と【表面的なケア】にあります。」
   - 熱い想いを伝えるコールアウト：「どうか、RICHEに【2時間】だけお時間をください。」
3. **選ばれる理由・解決策（3 Reasons）**:
   - 写真に頼らず、言葉の本質的な価値を伝えるテキスト特化型3カラムカード。
   - 01: 手ぐしだけでまとまる「骨格補正オートクチュールカット」
   - 02: 一過性ではない本物のツヤ「深層ナノ髪質改善エステ」
   - 03: 人目が気にならない「全席半個室」× フルフラットYUMEスパ
4. **お客様の口コミ（Reviews）**:
   - 総合評価 ★4.92 / リピート率 94.8% を裏付けるリアルな高評価口コミ4名分。
5. **看板メニュー＆料金案内（Menu & Price）**:
   - 明瞭会計、10日間の無料技術保証制度を明記した3つの初回おすすめプラン。
6. **よくある質問（FAQ / Q&A）**:
   - 初めてのお客様が抱く不安（似合う髪型の相談、当日予約、保証、決済方法、半個室のプライベート感）を解消するアコーディオン。
7. **24時間WEB予約・事前相談フォーム**:
   - 入力順序：ご希望メニュー・相談内容・希望日時を先、個人情報は後から入力させる離脱防止設計。
   - 送信後アクション：「通常24時間以内にサロンよりメールをお送りします」の安心明記。
8. **決定打となる予約CTAバナー**:
   - 「今、あなた史上最高の美しい髪と出逢う。」24時間WEB予約とお電話窓口への直感的な誘導。

## 📱 スマートフォン表示（モバイルファースト）への徹底的なこだわり

- **文節キープ（`.phrase`）**:
  単語や助詞の途中での不自然な改行（「泣き別れ」）をCSSで完全に防止。画面幅が狭いスマホでも文節単位で美しく折り返されます。
- **スマホ専用改行（`<br class="sp-only">`）**:
  1行あたり10〜16文字のリズム良く読める長さに合わせ、スマホ表示の時だけ自然に改行。
- **約物詰め（`font-feature-settings: "palt"`）**:
  句読点やカッコの余白を詰め、雑誌のように整ったプロポーショナル組版を実現。
- **画面下部固定予約バー**:
  スマホ閲覧時、いつでも1タップで電話・WEB予約ができる追従バーを完備。

## ⚙️ 予約リンク・店舗情報の一元管理（Single Source of Truth）

ホットペッパービューティーの予約URLや店舗電話番号は、[config.js](./config.js) で一元管理されています。
本番用の予約URLが決まり次第、`config.js` の1行を書き換えるだけで、サイト内のすべての予約ボタン・モーダルリンクへ一括反映されます。
